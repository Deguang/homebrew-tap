# Deguang Tap

## How do I install these formulae?

`brew install deguang/tap/<formula>`

Or `brew tap deguang/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "deguang/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
